# 第47届技术比武AI应用实操考试 · 设备维护样例数据说明

> 本数据用于「设备维护数据分析网页展示系统」实操考题，为模拟某生产单位设备维护业务生成的**样例数据**，非真实企业数据。数据共两个文件，均可用 Excel / WPS / Python（pandas）直接打开。

---

## 预埋脏数据（即 "数据识别与处理" 考核点，约 3% 以内）\**

- 空值：维修人员 75 条、故障类型 56 条、停机时长 37 条、购置金额 2 条、已报废但报废日期缺失 1 条
- 格式错乱：斜杠日期 11 条、设备编号带空格 10 条（不清洗会 JOIN 不上）
- 逻辑异常：报修早于投用 3 条、停机时长为 0 的 3 条、现象与故障类型不一致 3 条

## 三、业务口径说明（建议出题时写入考生须知）

1. **设备使用周期定义**：已报废设备 = 报废日期 − 投用日期；在用设备 = 数据截止日（2026-09-22）− 投用日期（即"已运行时长"）。
2. **累计字段口径**：台账中的累计维修次数 / 停机时长 / 维修费用 = 该设备全部维修记录求和（已按此回填，可交叉验证）。
3. **"周期—故障频次"关联**：数据整体呈现「使用周期越长、累计维修次数越多」的正相关趋势（全量 Pearson 相关系数约 0.79），同类别设备之间亦可对比，适合作为任务2的分析结论。
4. **类别差异**：不同类别设备故障类型偏好明显不同（如注塑机以液压故障为主、PLC控制柜以控制/软件故障为主、变压器外部因素占比高），适合做任务3的多维分析。
5. **季节规律**：制冷机组、空压机、变压器、配电柜故障在 7—9 月夏季高温期偏多，风机在 1—2 月冬季偏多，可做月份停机时长分析。

## 四、数据中预埋的脏数据（即考题「原始数据识别与处理」考核点）

> 为贴近真实业务，数据中预埋了少量（总量约 3% 以内）脏数据，考生需在读取后识别并处理。**注意：以下清单为出题依据，考生卷面上不应出现。**

| 类别         | 位置            | 数量   | 说明                                 |
| ---------- | ------------- | ---- | ---------------------------------- |
| 空值         | 台账·购置金额(万元)   | 2 条  | 未录入                                |
| 空值（缺失关键字段） | 台账·报废日期       | 1 条  | 设备状态为"已报废"但报废日期为空，周期统计时需特殊处理       |
| 空值         | 维修记录·维修人员     | 75 条 | 未填写                                |
| 空值         | 维修记录·故障类型     | 56 条 | 现象描述为"未记录"                         |
| 空值         | 维修记录·停机时长(小时) | 37 条 | 未填写                                |
| 格式错乱       | 台账·投用日期       | 1 条  | 斜杠格式（如 2006/10/24），其余为 ISO 格式      |
| 格式错乱       | 维修记录·报修日期     | 10 条 | 斜杠格式                               |
| 格式错乱       | 台账·设备编号       | 5 条  | 编号尾随空格                             |
| 格式错乱       | 维修记录·设备编号     | 5 条  | 编号带前导/尾随空格，不做处理会 JOIN 不上           |
| 逻辑异常       | 维修记录·报修日期     | 3 条  | 早于该设备投用日期（录入错误），其中 2 条伴随完成日期早于报修日期 |
| 异常值        | 维修记录·停机时长(小时) | 3 条  | 为 0（零停机维修，需业务判断是否合理）               |
| 字段错乱       | 维修记录·故障现象描述   | 3 条  | 现象与故障类型不一致                         |

**清洗提示**：编号先 `strip()` 再关联；日期统一解析为 ISO 格式；空值按"剔除 / 填充 / 单独归类"策略处理；逻辑异常行建议剔除并在分析中说明。

## 五、与考题任务的对应关系

| 考题任务             | 数据支撑                                                 |
| ---------------- | ---------------------------------------------------- |
| 任务1 台账展示         | `设备台账数据.csv` 全量 1080 台，支持按设备类别/车间/状态/名称筛选            |
| 任务2 使用周期统计       | 投用日期 + 报废日期 + 数据截止日；台账累计维修次数支撑"周期—故障频次"关联分析          |
| 任务3 多维分析（选做至少2项） | 故障类型分布、月份停机时长（含季节规律）、车间/类别维修频次与费用、维修方式占比、报废原因分布等均可计算 |
| 任务4 账号权限         | 与数据文件无关，考生自行实现本地账号存储（数据不提供账号，需考生自建）                  |
