# 设备维护台账数据分析网页系统

**抽签序号：26**，统一读取 `exam_id.txt`。在已有项目上按三份考试材料完善数据清洗、竖向导航、分析与后端权限。

## 下载、运行、打包

在 GitHub 点击 **Code → Download ZIP**，完整解压到可写目录。安装 Python 3.12 64 位后，双击 `run.bat`；浏览器访问 `http://127.0.0.1:8765`。

| 角色 | 用户名 | 初始密码 |
| --- | --- | --- |
| 管理员 | admin | Admin@123456 |
| 普通用户 | user | User@123456 |

Windows CMD（项目根目录）：

```bat
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements-build.txt
.venv\Scripts\python.exe verify.py
build.bat
```

成功后自动打开 `delivery\26`，其中 `26.exe` 为正式程序，另生成 `delivery\26.zip`。先停止原 Python 服务再验收 EXE。`build.bat onedir` 提供目录模式兜底；onefile 已内置默认原始CSV和抽签号，首次启动仅补齐缺失文件，不覆盖已有输入与账号。

**Windows EXE 必须在 Windows 本机构建并验收，Linux 打包回归不代表 Windows 运行已通过。** 每次更新源码后都必须重新打包。

## 本次优化

- 左侧竖向菜单、当前页高亮、表格内部横向滚动，桌面及窄屏布局适配。
- 原始台账1080行、维修3761行。按样例说明剔除时间逻辑异常维修3条，**提交维修CSV为3758行**；完整台账仍为1080行。原始文件和剔除明细保留。
- 本地可审查词典识别3条故障现象/类型疑似冲突；保留原类型及依据，归入“未分类”待复核，不擅自确认候选类型。清洗后未分类59条，其中原始缺类型56条。
- 逐台对账累计次数、停机、费用，并按有效维修明细重算清洗台账。缺失时长不当0、不用差额补造；原值、差异和无法完整核验的原因均可追溯。
- 生命周期三项分析，以及故障分布、月份停机、各设备维保频次、车间维保、类别维保、维修方式、报废原因、类别故障差异、季节分布共九类运维方向，每项有表格与图表。全系统15张本地PNG。
- 每次业务请求先查SQLite中的用户与角色；未登录重定向登录，普通用户GET/POST账号管理均返回403。密码哈希存储，退出清除session，进程重启保留账号。

## 已有账号的升级

建议下载到新目录。若需要保留旧程序创建的账号，先停止旧服务，将旧程序旁的整个 `runtime` 文件夹复制到新程序旁，再启动；不要删除、覆盖其中的数据库或session密钥。新程序不会重置已有账号。请勿把个人账号库提交到GitHub。

技术栈：Python、Flask、pandas、matplotlib Agg、SQLite、Jinja2、HTML/CSS；所有资源和核心计算均在本地，无CDN、Node或外部数据库服务要求。可选 LLM 分析通过 Python 标准库 urllib 调用 DeepSeek。

## 可选 DeepSeek 智能分析（新增）

管理员登录 → 左侧「LLM 智能分析」→ 粘贴自己的 DeepSeek API Key → 保存。随后管理员和普通用户都能使用「综合使用情况」「生命周期与更新」「故障与停机」「费用与维保」按钮，或输入问题连续对话；可选填完整设备编号进行单台设备分析。刷新页面清空对话，密钥在本机保存并跨重启保留。

密钥存于 `runtime/deepseek.key`，不回显、不进 GitHub、不进打包 ZIP；亦支持 `DEEPSEEK_API_KEY` 环境变量（优先于文件）。新下载的程序需自行在网页保存一次密钥。普通用户不能保存或更改服务密钥，后端直接拒绝该请求。

点击分析会把本地统计摘要、问题及最近三轮对话发送至 `api.deepseek.com`，消耗额度；不上传账号库、密码、维修人员姓名或整份原始 CSV。模型提供文字建议，不参与本地数据计算或权限判断。联网失败、密钥无效、余额不足或超时时显示错误，清洗、报表、图表均不受影响。

**验证边界：** LLM 页面、后端权限、密钥持久化、请求格式及离线/错误处理通过自动测试。当前云环境无法解析 DeepSeek 域名，无业务数据的连接测试也失败，因此尚未确认此密钥有效或真实模型回复成功；请在联网的 Windows 电脑点击按钮完成现场验证。记录见 `validation/deepseek_live_26.json`。
